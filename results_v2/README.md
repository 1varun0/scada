# results_v2 — SCADA Hybrid IDS Empirical Audit & Results Directory

- **Project**: SCADA Hybrid IDS with Live Simulation
- **Purpose**: Fully reproducible, code-executed empirical results directory.
- **Rule Compliance**: Every number in this directory was generated by executing code against real datasets in an isolated external sandbox (`%TEMP%\p1_sandbox`), with raw outputs preserved verbatim in [`raw/`](raw/) and markdown tables compiled via automated scripts in [`scripts/`](scripts/).
- **Baseline Git Commit**: [`27d13c2`](_env/commit_hash.txt)
- **Host Hardware**: Intel Core i5-10300H (4C/8T), 15.84 GB RAM, NVIDIA GeForce GTX 1650 (4 GB VRAM), Windows 11.
- **Runtime**: Python 3.12.6 (64-bit), PyTorch 2.5.1+cu121 (CUDA 12.1 enabled).
