# results_v2 — Empirical Results & Verification Suite

- **Project**: SCADA Hybrid IDS with Live Simulation
- **Purpose**: Fully reproducible, code-executed empirical results directory.
- **Rule Compliance**: Every number in this folder is produced by executing code against real datasets in an isolated external sandbox, with raw logs captured in `results_v2/raw/` and summary tables generated by scripts in `results_v2/scripts/`.
- **Baseline Git Commit**: `27d13c25bfd64e4d82e50aabadaefb7ff6498c71`
- **Creation Date**: 2026-10-13

## Directory Layout
- `_env/`: Environment specifications (OS, Python, pip freeze, CPU, RAM, GPU, library versions).
- `_audit/`: Integrity tracking (`PROGRESS.md`, `hashes_before.txt`, `hashes_after.txt`, `determinism.md`, `FINAL_REPORT.md`).
- `scripts/`: Generation and verification scripts for tables, metrics, and figures.
  - `sandbox_patches/`: Diffs applied strictly to the sandbox copy for path or runner accommodation.
- `raw/`: Verbatim captured stdout, stderr, and execution JSON metadata sidecars.
- `tables/`: Script-generated markdown table fragments.
- `figures/`: Matplotlib generated figures (PNG) and accompanying CSV data tables.
- `docs/`: Numbered result analysis documents (R00 to R14).
