# Source File Note: `evaluation/reporter.py`

## Purpose
Generates persistent markdown report tables and visual diagnostic plots (ROC curve) summarizing evaluation and ablation experiments.

## Public Classes and Functions
- `class Reporter(output_dir: str = "reports")`
  - `__init__(output_dir: str = "reports")`: Ensures output directory exists.
  - `generate_ablation_markdown(df_ablation: pd.DataFrame, filename: str = "ablation_results.md") -> str`: Formats ablation DataFrame by rounding floats to 4 decimal places, converts to GitHub markdown table format via `.to_markdown()`, prepends heading `# Ablation Study Results`, and writes to disk. Returns filepath.
  - `plot_roc_curve(y_true, y_scores, title="ROC Curve", filename="roc_curve.png") -> str`: Computes FPR, TPR via `sklearn.metrics.roc_curve`, calculates area under curve, plots curve using Matplotlib, saves figure to disk, and closes plot. Returns filepath.

## Inputs and Outputs
- `generate_ablation_markdown()`:
  - Input: Pandas DataFrame of ablation results.
  - Output: String path of generated markdown file (`reports/ablation_results.md`).
- `plot_roc_curve()`:
  - Inputs: `y_true`, `y_scores`, optional title and filename strings.
  - Output: String path of generated plot image (`reports/roc_curve.png`).
